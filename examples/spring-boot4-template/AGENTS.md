# Boot4 sample research rules

Read README.md. This sample has its own Gradle8.14 wrapper, isolated from the root
wrapper. Use the local source artifacts and keep one owned app on8084 at a time.
The starter detects a startup agent; it does not attach one. Do not add a manual
flag in plugin mode or attribute an unattached control's lack of reload to a defect.

For each mode, keep one PID through controller-body, added-endpoint, record-field,
configuration-value and added-service checks. Compile with the same mode/repository;
do not restart to manufacture a passing result. Restore sample mutations afterwards.
Collect actual HTTP and agent logs. No agent/plugin/starter product fix belongs in
the initial research stage; a finding requires a new plan and independent review.
