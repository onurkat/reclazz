Install from JetBrains Marketplace (recommended)

  1. In IntelliJ IDEA, open Settings → Plugins → Marketplace, search Reclazz and choose Install. Restart IntelliJ if prompted.
  2. Open your SAP Commerce project. In Settings → Tools → Reclazz, tick Enable Reclazz in this project and choose Apply.
  3. Choose Install Agent in the SAP Commerce section. The agent is included; the plugin backs up the startup-properties file.
  4. Follow the setup check. If wrapper options differ, run ant server, then restart your development server. The detailed guide explains these commands.
  5. Choose Check setup. Once connected, change an existing method, compile with your usual build and repeat the same application action.

It worked when the same server returns your changed result without another restart.

Start with one working reload

Attach Reclazz once, compile a small Java edit and check the changed result in the running server.

  1. Follow the IntelliJ + SAP Commerce setup.
  2. Start the server with the agent and wait for watching to begin. Under hybrisserver.sh, hybrisHome= is optional: SAP Commerce supplies HYBRIS_BIN_DIR. Keep an explicit override for other startup paths.
  3. Compile your edit, repeat the same operation and check its actual result.
