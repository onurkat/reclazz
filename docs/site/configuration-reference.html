Agent argument syntax

shell
java "-javaagent:/absolute/tools/reclazz-agent-X.Y.Z.jar=watchDirs=/absolute/app/target/classes,verbose=true" -jar app.jar

Use comma-separated key=value pairs after the agent JAR’s equals sign. Lists use semicolons where documented. Quote the complete agent argument when paths contain spaces. The parser splits commas only where a known key follows; avoid appending unknown keys to another value.

These are application-JVM startup options. Match them to the installed agent version. The full table below is generated from the canonical usage guide in this documentation build; no new runtime dependency is introduced by the docs.
