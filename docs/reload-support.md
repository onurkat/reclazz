# Reload support reference

This is the canonical support table. The interactive [reload matrix](https://reclazz.com/docs/support-matrix/)
and its downloadable JSON are generated from these rows; edit this file, never generated output.
Each result applies only to its stated condition and linked scope. An unverified result
is neither a success nor a refusal. Java 17+ is a target, not certification of every vendor or OS.
