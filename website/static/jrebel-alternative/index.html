A free JRebel alternative for Spring Boot and SAP Commerce

Reclazz does the job most teams buy JRebel for: it loads your changed classes into the server that is already running, so you skip the restart. It is free, Apache 2.0, and needs no licence key.

What you get either way

  • Your changed Java classes go into the running JVM. No restart, and you stay logged in.
  • An IntelliJ IDEA plugin that sets everything up.
  • Spring beans and MVC mappings follow your class changes.

When JRebel is still the better choice

Pick JRebel if your team works in Eclipse, NetBeans or VS Code, runs Java 8 to 16, or needs one of the roughly 100 frameworks and application servers it integrates with. Reclazz focuses on Java 17+, Spring and SAP Commerce, and does that part for free.

Moving from JRebel to Reclazz

  1. Remove the JRebel agent from your run configuration. Use one reload tool per JVM.
  2. Install Reclazz from JetBrains Marketplace and open your project. The setup window opens by itself.
  3. Change a method, build, and repeat the request. You should see the new result from the same server.
