Install the plugin and try a Java edit

Install Reclazz from JetBrains Marketplace and open the project you want to edit. If the wizard is already open, start there. You can reopen it from Tools → Set Up Reclazz.

Install the IntelliJ plugin

The wizard follows your project type

Java / Spring

Choose Turn on Reclazz in the wizard, then run or debug your Java application from IntelliJ. Connecting an AI assistant is optional.

SAP Commerce

  1. 1Add the agent to local.properties

    Review the changes to local.properties, then choose Install Reclazz.

  2. 2Run ant server

    Choose Run ant server. When it finishes, restart your server once to load the agent.

  3. 3Connect an AI assistant (optional)

    Optional. Connect your AI assistant to see reload results, or finish setup and work in the IDE.

Change the response from a method

  1. Start the application with the agent and wait for the reload watcher to be ready.
  2. Change the text returned by an existing Java method. Build the class into the output directory the agent watches.
  3. Call the method again or refresh its page. You should see the new text in the running application.
Check the expected output in the quickstart

Reopen the wizard or change a setting

Open Settings → Tools → Reclazz to review the settings for this project. To repeat a setup step, open Tools → Set Up Reclazz.
