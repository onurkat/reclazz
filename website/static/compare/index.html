When another tool is the better choice

JRebel

Choose its IDE integration if your team uses Eclipse, NetBeans, MyEclipse or Visual Studio Code. Its integration list covers about 100 technologies and Java 8 and newer, beyond Reclazz’s Java {{CLAIM:agent_java_min}}+, Spring and SAP Commerce focus. JRebel integration and JVM list.

Spring Boot DevTools

If application restarts are fast enough, start with a build dependency. DevTools replaces the application classloader when the classpath changes, so a superclass edit is picked up by a restart. Spring Boot Developer Tools reference.

Reclazz is Apache 2.0 and applies documented changes in place. Method-body edits keep object fields on the JVM-only path, while refreshed beans can reset their mutable state. Check the change you need.
