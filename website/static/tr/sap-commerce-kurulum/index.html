Reclazz ile SAP Commerce kurulumu

Yerel SAP Commerce sunucunuzu IntelliJ üzerinden Reclazz’a bağlayın. Ajanı eklentiyle veya local.properties dosyasını düzenleyerek ekleyebilir, ardından küçük bir Java değişikliğiyle kurulumu doğrulayabilirsiniz.

Reclazz yalnızca geliştirme ortamı içindir. Production'a, CCv2 manifest'ine ya da projenin build'ine girmez; eklediğiniz satır sizin makinenizde kalır.

JetBrains Marketplace'ten kurun (önerilen)

  1. IntelliJ IDEA'da Settings → Plugins → Marketplace ekranını açın. Reclazz arayın ve Install seçin; istenirse IntelliJ'yi yeniden başlatın.
  2. SAP Commerce projenizi açın. Settings → Tools → Reclazz ekranında Enable Reclazz in this project kutusunu işaretleyip Apply seçin.
  3. SAP Commerce bölümündeki Install Java Agent düğmesine basın. Java ajanı eklentinin içindedir; güncellenen başlangıç ayarlarının yedeği alınır.
  4. Kurulum kontrolündeki önerileri izleyin. Wrapper seçenekleri farklıysa ant server çalıştırın, ardından geliştirme sunucunuzu yeniden başlatın. Aşağıdaki adım bu komutları gösterir.
  5. Check setup bağlantısını açın. Java ajanı bağlanınca mevcut bir metodu değiştirin, kullandığınız yöntemle derleyin ve aynı uygulama işlemini tekrarlayın.

Aynı sunucu yeniden başlamadan değiştirdiğiniz sonucu döndürüyorsa ilk reload çalışmıştır.

Aşağıdaki örneklerde HYBRIS_HOME, kurulumunuzdaki hybris klasörünün tam yoludur (örneğin /Users/ad/projeler/proje/hybris).

1. IntelliJ eklentisini kurun

  1. IntelliJ'de Settings → Plugins → Marketplace açın, Reclazz arayın ve kurun.
  2. IDE yeniden başlatma isterse yeniden başlatın.

Sonra iki yoldan birini seçin. Kolay yolda eklenti Java ajanı sizin yerinize kurar. Manuel yolda ayarları kendiniz düzenlersiniz. İkisinin sonunda 3. adımdan devam edin.

2A. Kolay yol: Install Java Agent

  1. Settings → Tools → Reclazz ekranında Enable Reclazz in this project kutusunu işaretleyin.
  2. SAP Commerce bölümünde Compile Java in the IDE instead of ant kutusunu işaretleyin.
  3. Install Java Agent düğmesine basın. Eklenti Java ajanı local.properties dosyasına (opsiyonel config klasörü varsa 95-local.properties) işaretli bir blok olarak yazar ve dosyanın yedeğini alır.
  4. Ekranda "Agent installed in the server startup properties" yazmalı.
  5. Yazılan dosyada tomcat.debugjavaoptions satırını kontrol edin: debug bayraklarınız (-Xdebug, -Xrunjdwp:...) durmalı ve satırda tek bir -javaagent:...reclazz-agent.jar olmalı. Gerekirse elle düzeltin.

Çalışan Java ajana bağlıyken AutoCompile, ImpEx import, Allow REMOVE, Backoffice reset, Update Running System ve Solr reindex seçenekleri Apply ile ve yeniden bağlanınca canlı uygulanır. Ayarlardaki durum satırı Java ajanın gerçekte kullandığı değerleri ya da bekleme/hata sonucunu gösterir. Watch extensions içindeki keşfedilmiş eklentiler adlarıyla canlı eklenip çıkarılabilir. Önceden yüklenmiş ve enstrümante edilmemiş sınıflarda yeniden başlatmaya kadar yalnız gövde değişir; sonradan yüklenen sınıflar yapısal reload desteği alabilir. * veya boş listeyle tümünü izlemeye geçiş ve diğer başlangıç ayarları için Reinstall düğmesine basıp 3. adımı tekrarlayın.

Yazılan blok makineye özel bir yol içerir; dosya git'te tutuluyorsa commit etmeyin.

2B. Manuel yol

Ayarları kendiniz yönetmek istiyorsanız bu üç adımı izleyin; Install Java Agent düğmesine basmayın.

Manuel 1. Java ajanı sabit bir konuma kopyalayın

Java ajanı eklentinin içinde gelir; ayrıca indirmeniz gerekmez. Ancak eklenti klasörünün yolu IDE sürümüyle değişir (örneğin IntelliJIdea2025.2, IntelliJIdea2026.1). Sunucuya bu yolu yazarsanız IDE güncellendiğinde sunucu Java ajanı bulamaz. Bu yüzden jar'ı bir kez sabit bir yere kopyalayın.

  1. Eklentinin içindeki jar'ı bulun (<sürüm> yerine kullandığınız IntelliJ'in klasörü, Community sürümünde IdeaIC...):
    • macOS: ~/Library/Application Support/JetBrains/IntelliJIdea<sürüm>/plugins/reclazz/agent/reclazz-agent.jar
    • Windows: %APPDATA%\JetBrains\IntelliJIdea<sürüm>\plugins\reclazz\agent\reclazz-agent.jar
    • Linux: ~/.local/share/JetBrains/IntelliJIdea<sürüm>/plugins/reclazz/agent/reclazz-agent.jar
  2. Dosyayı tam olarak şu konuma kopyalayın: ~/.reclazz/agent/reclazz-agent.jar (Windows'ta kullanıcı klasörünüzün altında .reclazz\agent\reclazz-agent.jar).

macOS için komut (Linux'ta kaynak yolu yukarıdaki Linux yoludur):

mkdir -p ~/.reclazz/agent
cp ~/Library/Application\ Support/JetBrains/IntelliJIdea<sürüm>/plugins/reclazz/agent/reclazz-agent.jar ~/.reclazz/agent/

Bu konumdaki kopyayı eklenti her IDE açılışında güncel tutar; eklentiyi güncellediğinizde sunucunun Java ajanı da güncellenir.

Manuel 2. local.properties dosyasını elle düzenleyin

SAP Commerce sunucusu Tanuki wrapper ile başlar. tomcat/conf/wrapper.conf her ant çalıştığında yeniden üretilir; oraya yazılan satır kaybolur. Doğru yer platformun kendi ayarlarıdır: tomcat.javaoptions (normal başlatma) ve tomcat.debugjavaoptions (debug başlatma).

  1. HYBRIS_HOME/config/local.properties dosyasını açın.
  2. Bu iki ayar zaten varsa değerlerini silmeyin; Java ajanı mevcut değerin sonuna ekleyin. Özellikle tomcat.debugjavaoptions genelde -Xdebug ve -Xrunjdwp:... gibi debug bayraklarını taşır, silerseniz debug çalışmaz.
  3. Her iki satırda da yalnızca bir tane -javaagent:...reclazz-agent.jar olsun.
tomcat.javaoptions=<mevcut değerler> -javaagent:/Users/ad/.reclazz/agent/reclazz-agent.jar=autoCompile=true
tomcat.debugjavaoptions=<mevcut debug bayrakları> -javaagent:/Users/ad/.reclazz/agent/reclazz-agent.jar=autoCompile=true

hybrisHome=, hybrisserver.sh ile başlatmada isteğe bağlıdır: Java ajanı kurulumu SAP Commerce'in kendi HYBRIS_BIN_DIR bilgisinden bulur. JVM'i başka yolla başlatıyorsanız veya bilinçli bir override istiyorsanız kullanın. Açık değer çakışırsa uyarı verilir ve açık değer korunur. Managed Reinstall bu gereksiz argümanı çıkarır; doğrudan IDE başlatma ve attach açık yolu korur.

autoCompile=true kaydettiğiniz Java dosyasını ant build beklemeden Java ajana derletir. Elle eklenen satır başlangıç varsayımıdır; IDE Java ajana bağlandığında yukarıdaki altı canlı seçenek Settings'teki kayıtlı değerlerle eşitlenir. IDE bağlantısı yoksa başlangıç satırı geçerlidir. Canlı değişiklik satırı yeniden yazmaz. Satırlar makineye özel yol içerir; local.properties git'te tutuluyorsa commit etmeyin.

Manuel 3. IntelliJ'de Reclazz'ı açın (otomatik kurulum olmadan)

  1. Projeyi IntelliJ'de açın. Bir Reclazz bildirimi Install Java Agent ya da Enable Reclazz düğmesiyle gelirse basmayın; ikisi de Java ajanı sizin yerinize ayarlara yazar. Bildirim hiç çıkmayabilir, sorun değil.
  2. Settings → Tools → Reclazz ekranını açın.
  3. En üstteki Enable Reclazz in this project kutusunu işaretleyin. Bu kutu ayarlara bir şey yazmaz. Açıkken eklenti "Reclazz is off" önerisini artık göstermez ve ayarlardaki Java ajanı jar'ı silinmişse sizi uyarır. IntelliJ Java ajana bu kutudan bağımsız olarak bağlanır.
  4. SAP Commerce bölümündeki Install Java Agent düğmesine basmayın.
  5. OK ile kaydedin.

Elle kurulumda bu ekranda şunları görmeniz normaldir:

  • Agent not installed in the server: Eklenti yalnız kendi yazdığı bloğu arar; elle eklenen satırı burada göstermez. Java ajanın çalıştığını sunucu konsolundan ve bağlantı durumundan anlarsınız.
  • Agent: not connected: Sunucu kapalıyken böyle yazar. Sunucu açılınca IntelliJ Java ajana HYBRIS_HOME/.reclazz/agent.port dosyası üzerinden bağlanır; Test connection ile kontrol edebilirsiniz.

3. Ayarları uygulayın ve sunucuyu başlatın

Başlangıç satırındaki ayarlar wrapper.conf dosyasına ancak ant ile geçer. Bu varsayımları kalıcı değiştirmek için sadece sunucuyu yeniden başlatmak yetmez; canlı seçenekler ise bağlı Java ajanda ayrıca uygulanır.

cd $HYBRIS_HOME/bin/platform
. ./setantenv.sh
ant server
./hybrisserver.sh          # debug için: ./hybrisserver.sh debug

Windows'ta aynı klasörde setantenv.bat, ant server ve hybrisserver.bat kullanın.

Sunucu açılırken konsolda Reclazz satırlarını görmelisiniz:

[Reclazz] [INFO] Agent loaded via -javaagent (premain)
[Reclazz] [ OK ] Reclazz is active. Watching for changes...
[Reclazz] [INFO] Watching ... directories

Bu satırlar yoksa Java ajanı yüklenmemiştir; önce Sorun giderme bölümüne bakın. IntelliJ'in alt durum çubuğundaki gösterge de "Reclazz: Connected" yazar; "Reclazz: Not connected" kalıyorsa Java ajanı sunucuya bağlanmamıştır.

4. İlk deneme

Kurulumun çalıştığını görmenin en kısa yolu, sık kullandığınız bir endpoint'te küçük bir değişikliktir.

  1. Bir OCC controller'ın ya da servisin döndürdüğü bir değeri seçin ve endpoint'i çağırıp cevabı not edin.
  2. Metodun içindeki dönen metni değiştirin ve dosyayı kaydedin.
  3. Konsolda Compiled ...java ve ardından Reloaded ... satırlarını bekleyin; genelde bir iki saniye sürer.
  4. Endpoint'i tekrar çağırın. Yeni metin gelmeli; sunucu yeniden başlamamalı.

Sorun giderme

Önce Settings → Tools → Reclazz → Check setup bağlantısını açın. Her satır kurulumdaki bir kontrolü ve gerekiyorsa çözümünü gösterir: normal/debug Java ajanı seçenekleri, üretilen wrapper, debug bayrakları, JAR sürümü, sunucu JDK'sı, diğer Java ajanlar ve izlenen uzantılar. Sunucu açıksa çalışan Java ajanı sürümü ve DOCTOR özeti de görünür; kapalıysa bu adım atlanır. Kontrol dosya oluşturmaz veya değiştirmez.

Install Java Agent veya Reinstall başarılı olunca kurulum sonucu hemen gösterilir; aynı kontrol otomatik çalışır ve özeti ayrı bir bildirimle iletilir. Wrapper seçenekleri gerçekten farklıysa ant server önerilir; ilgisiz bir properties değişikliğinin tarihi tek başına hata sayılmaz. Önerilen düzeltmeden sonra yeniden kontrol edin.

Kaldırma

  1. Kolay yolla kurduysanız: Settings → Tools → Reclazz → SAP Commerce bölümünde Remove bağlantısına tıklayın; eklenti kendi bloğunu ya da 95-local.properties dosyasını kaldırır. tomcat.debugjavaoptions satırını elle düzelttiyseniz oradaki -javaagent:... kısmını da silin.
  2. Manuel kurduysanız: local.properties dosyasında iki satırdan yalnızca -javaagent:...reclazz-agent.jar... kısmını silin; diğer değerlere ve debug bayraklarına dokunmayın.
  3. ant server çalıştırıp sunucuyu yeniden başlatın.
  4. İsterseniz IntelliJ'de Enable Reclazz in this project kutusunu kapatın ya da eklentiyi kaldırın.

Projenin koduna ve build'ine hiçbir şey eklenmediği için kaldırmak bu kadardır.
